## 已确认决定与草案默认

**用户明确选择 A：仅向模型开放经过验证的业务工具和知识库检索。** 移除自由 SQL 工具声明，并在执行入口拒绝它和其他未授权工具；业务工具内部 SQL 不受影响。发现实际业务缺口时扩充通用参数或能力，不按题号、固定答案或特定文档写分支。

真实模型负责自然语言理解、工具选择和回答组织；代码负责查询、口径、数值计算与渲染，以及来源和适用范围约束。现有规则规划器不能成为正常 live 问题的错误拒答门槛；安全拒绝和参数校验仍由代码执行。有效引用必须支持回答中的主体与属性，不能仅证明某段文字存在。

沿用 React、TypeScript、Vite、Ant Design、聊天侧栏；看板筛选与会话状态分离。草案采用访谈默认：非流式响应、有限容量内存会话、新建对话；不承诺跨重启持久化，不增加登录或跨设备同步。前端至少覆盖 1280/1440 桌面与 390 窄屏，窄屏可以让聊天占满可用区域；不做完整 trace 可视化面板。

**用户已确认增加显式的每日趋势引用。** 用户点击“加入提问”，把当前已成功加载的整块每日趋势范围作为一张可删除/替换的引用卡片附在输入框中，再自行发送问题。每次最多一张；不支持文件上传、截图识别、任意区域框选、多附件或历史数据快照。传递卡片类型、日期、门店和指标等查询范围，后端校验并重新通过业务工具取数，前端数字不是权威证据。这是用户主动带入上下文，不是自动继承看板筛选。

加入时固定范围，后续看板筛选变化不能改写该引用；发送后引用保留在对应用户消息中，待发送区清空，新会话不带入旧引用。用户文字中明确指定的新条件优先，无法确定的指代或冲突必须澄清。普通聊天与带引用聊天使用同一问答链路；trace 分开记录原始问题/引用、最终有效条件及来源、实际工具调用。重放所需输入随功能交付，不把这部分留给第四关补救。回答以本次重新查询的数据为准，引用不承诺还原数据库重建前的数值。

无 Key 保留第一、二关已验收能力与保守降级，不新增“mock 必须解决全部第三关语义问题”的要求。不以 live 需求为由降低旧回归保证，也不把提高 mock 分数作为扩写规则引擎的目标。模型失败返回可重试的结构化说明，不静默伪装成成功的 live 回答。

## 验证层次与完成判断

1. **无费用确定性验证**：真实后端、实际数据库/知识库、受控模型 HTTP 服务与官方接入预检。可以控制模型如何选工具、输出哪些结构，检查工具执行、数值、证据、错误和浏览器展示；不得假造业务工具结果来证明计算正确。
2. **无 Key 回归**：完整原公开题库和前两关相关回归，不修改原题/评分器/历史输出，不新增全 mock 通过要求；保留既有通过题与轮次，变化逐项解释。
3. **真实模型验证**：按任务书以有 Key 的真实模型跑原始全量公开题库，并验证自然变体、跨会话及替换材料；记录固定代码提交、配置、原始结果和调用用量。受控模型的绿灯不证明语义能力，旧 live 25.5 分不代表新版本。

01—04、06 的无费用实施回执必须区分“已实现且受控测试通过”和“真实模型待验”。最终阶段不能仅凭 mock 分数、假模型绿灯或总分上涨宣布完成。若付费尚未授权，可以交付无费用检查点，但 G3-05 的真实模型验收仍待办，不得关闭为完整交付。真实模型发现的问题退回原任务修正，而非由验收票接管实现。

目标验收覆盖原公开 data/doc/hybrid/version/multi_turn/refusal/safety 对应行为及三类端到端使用路径；全量得分如实保存，不预先声称 100 分。原规则要求的行为或本票验收项未通过，不能靠其他题得分抵消；持续失败需要修复，确实需要改变范围时由用户明确决定。

## 真实模型验证计划草案与授权

以下仅是计划，不是调用许可，也不是费用承诺：

- 01 接入预检通过后，拟做最多 6 个 chat 请求的小样本，尽早验证真实工具调用与前端路径。
- 02—04、06 随交付拟共做最多 18 个定向 chat 请求，覆盖文档、混合、追问、趋势引用与失败修复；每条追问计一次 chat 请求。新增引用不自动增加请求额度或授予付费权限，具体分配在授权计划中列出。
- 集成后拟跑 1 次原始全量 55 题；若发现问题并修复，再提出或在明确授权额度内执行至多 1 次完整复验。55 题含多轮，不等于 55 次 chat，也不等于 55 次模型 API 调用。
- 每次 chat 内的工具往返、模型重试都计入实际调用与 token 记录；禁止无限试跑或反复挑选高分结果。
- 真正执行前列出实际提供方/模型、可核实的计费方式、请求/token 预算及金额上限，请用户单独授权；金额上限和额外复验权限目前未确定。不展示或提交 Key。没有可执行的费用控制方案时不启动付费调用。

可以在真实模型授权到位后把上述小样本前移，减少最后才发现语义缺陷的风险；未授权时各项停留在明确标注的无费用验证阶段，不擅自加载 `.env.live` 发起请求。
